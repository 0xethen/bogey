# @bogey/config

Defines Bogey's configuration. Values live elsewhere:

| Tier        | Values                                  | Defined here                                                 |
| ----------- | --------------------------------------- | ------------------------------------------------------------ |
| Environment | repo-root `.env`                        | (read by `@bogey/db` and the CLI)                            |
| Instance    | repo-root `bogey.config.ts`             | `defineConfig`, `InstanceConfig` (`src/define.ts`)           |
| Settings    | the `settings` table, edited in the app | `settingsRegistry`: schemas and defaults (`src/settings.ts`) |

- `@bogey/config`: `brand`, `security`, `disabledPlugins` from `bogey.config.ts`
- `@bogey/config/settings`: the registry, `resolveSettings`, `parseSettings`
- `@bogey/config/themes`: generated by `bogey themes` from `packages/ui/src/styles/themes`

`@bogey/db/queries/settings` reads and writes settings; it defines none.

A namespace's `fields` describe how Settings renders its keys: a label, and
option labels for enums (booleans get a switch). `SettingFields` in the app
renders any of them at any scope, showing where each value comes from.
