# Bogey

Bogey is a self-hostable platform for running competitions with entrants,
deadlines and judging. [Learn more about Bogey](../README.md)

These pages are the same files as `docs/` in this monorepo. The wiki is
generated from them on every push to `main`, so edit them there.

> Ensure that GitHub Wiki is enabled in your repository settings

## Start here

- [Getting started](getting-started.md): running Bogey on your machine. One app serves participants, judges and organizers.
- [Self-hosting](self-hosting.md): the all-in-one stack, Supabase Cloud or your own Supabase, sign-in email, domains, backups.
- [Configuration](configuration.md): where to find every setting.
